sana-upload

プライバシーポリシー

sana-upload（以下「本ツール」）は、運営者が自分の YouTube チャンネルへ動画を投稿するために使う個人用ツールです。一般の方に提供するものではありません。

1. 使う Google ユーザーデータ

  • 本ツールが使う権限は、運営者自身の YouTube チャンネルへの動画のアップロード、タイトル・概要欄の設定、投稿先チャンネル名の確認に限られます。
  • 視聴者や第三者の個人情報を取得することはありません。

2. 保存と共有

  • 認証の情報（アクセス用のトークン）は運営者のパソコン内にのみ保存し、外部へ送信したり、第三者に提供・販売したりすることはありません。
  • Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

3. 権限の取り消し

本ツールに与えた権限は、Google アカウントのセキュリティ設定からいつでも取り消せます。

4. 変更

本ポリシーは必要に応じて変更することがあります。変更後の内容は、当ページに掲載した時点から効力を生じます。

Privacy Policy (English)

sana-upload is a private tool used only by its operator. It uses the YouTube Data API solely to upload videos to, set titles/descriptions on, and confirm the name of the operator's own YouTube channel. It does not collect any data about viewers or other users. OAuth tokens are stored only on the operator's own computer and are never transmitted to or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account permissions.
